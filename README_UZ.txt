AVORA — boshlang‘ich Expo mobil ilova loyihasi

Bu ZIP ichida React Native + Expo boshlang‘ich prototipi bor.
Ilova o‘zbek, ingliz va rus tillari orasida almasha oladi.

Muhim: bu hali prototip. Login, haqiqiy ma’lumotlar bazasi, AI API va barcha bo‘limlarning to‘liq funksiyalari keyin ulanadi.

APK yaratish uchun:
1. ZIP ichidagi fayllarni GitHub repository'ga joylang.
2. https://expo.dev saytida hisob oching.
3. EAS Build orqali Android APK yig‘ing.
4. APK build sozlamasi eas.json ichida tayyor.

Qo‘llanma: https://docs.expo.dev/build-reference/apk/
